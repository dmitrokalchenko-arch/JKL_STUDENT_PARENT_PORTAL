# JKL Student & Parent Portal

Модуль **JKL Club** — единый семейный портал клуба. Название проекта
(`JKL_STUDENT_PARENT_PORTAL`) отражает конечных пользователей (студенты и
родители), а не архитектуру с двумя раздельными кабинетами.

## Назначение модуля

`JKL_STUDENT_PARENT_PORTAL` — это:

- **единый семейный портал**, а не два отдельных приложения для студента и
  родителя по отдельности;
- семейный аккаунт может включать одного или нескольких детей;
- родители и ребёнок могут использовать общие данные входа (общий
  логин/ник и пароль семейного аккаунта);
- внутри кабинета семья выбирает активного ребёнка — все разделы (профиль,
  тренировки, достижения, сертификаты, мероприятия, техники, договор и
  оплата) показывают данные только выбранного ребёнка;
- переключение между привязанными детьми происходит без повторного входа;
- тренеры используют отдельный, независимый от семейного аккаунта вход;
- тренер может открывать страницы доступных ему учеников — ту же страницу
  ученика, что видит семья, но с ограниченными правами (например, без
  доступа к чувствительным платёжным реквизитам);
- портал использует существующую основную базу JCL Club (`JCL_Gruppen`) —
  новая отдельная таблица студентов не создаётся, основным источником
  данных ученика остаётся уже существующая таблица `students`.

Подробное архитектурное описание — в
`docs/architecture/FAMILY_ACCOUNT_CONCEPT.md`. Черновик модели данных — в
`docs/database/FAMILY_ACCOUNT_DATA_MODEL_DRAFT.md`. Аудит существующей базы
`JCL_Gruppen` — в `docs/database/EXISTING_DATABASE_AUDIT.md`.

## Структура проекта

- `docs/` — архитектура, база данных, дизайн, дорожная карта, скриншоты.
- `memory/` — контекст проекта, продуктовое видение, правила UI, бизнес-правила,
  терминология, текущий статус работы.
- `prompts/` — промпты/сценарии для разделов студента, родителя и общих частей.
- `src/` — исходный код интерфейса (компоненты, страницы, стили, сервисы, утилиты).
- `public/` — публичные статические файлы.
- `supabase/` — миграции, политики доступа и документация базы данных.
- `tests/` — тесты.

## Статус

Проект находится на этапе начальной структуры. См. `memory/CURRENT_STATUS.md`.
