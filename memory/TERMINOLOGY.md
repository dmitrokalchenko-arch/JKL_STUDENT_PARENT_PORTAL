# Терминология

Раздел находится в стадии наполнения. Здесь фиксируются согласованные
термины и их определения для единообразного использования в коде,
документации и интерфейсе.

Проект по-прежнему называется **JKL_STUDENT_PARENT_PORTAL** — название не
меняется, несмотря на переход к единой концепции семейного аккаунта (см.
`docs/architecture/FAMILY_ACCOUNT_CONCEPT.md`).

## Общие термины

| Термин | Определение |
|---|---|
| Пояс | Уровень квалификации студента в системе аттестации клуба |
| Рейтинговые баллы | Баллы, накапливаемые студентом, влияющие на допуск/прогресс |
| Возраст допуска к экзамену | Минимальный возраст, при котором студент допускается к сдаче экзамена на пояс |
| Договор | Соглашение семьи (родителя/опекуна) с клубом об оказании услуг обучения ребёнка. Не путать с SaaS-договором клуба перед платформой JCL (`clubs.contract_*` в `JCL_Gruppen`, см. `docs/database/EXISTING_DATABASE_AUDIT.md`) |
| Оплаченный период | Временной интервал, за который семьёй внесена оплата по договору |

## Термины семейного аккаунта (актуальная концепция)

| Термин (RU / EN / DE) | Определение |
|---|---|
| **Family Account** / Familienkonto / Семейный аккаунт | Единая учётная запись семьи. Может быть связана с одним или несколькими детьми. Используется родителями и, при необходимости, ребёнком под одними и теми же данными входа. Это точка входа семьи в систему. |
| **My Family** / Meine Familie / Моя семья | Раздел семейного аккаунта. Показывает всех связанных (привязанных) детей. Позволяет выбрать ребёнка. В будущем позволяет добавлять родителя/опекуна и управлять семейным аккаунтом. |
| **Family Member** / Familienmitglied / Член семьи | Родитель, опекун или другой взрослый участник семейного аккаунта. |
| **Linked Student** / Verknüpfter Schüler / Привязанный ученик | Ученик, связанный с конкретным семейным аккаунтом. |
| **Selected Student** / Ausgewählter Schüler / Выбранный ученик | Ребёнок, данные которого сейчас отображаются в кабинете (активный в текущей сессии). |
| **Guardian** / Erziehungsberechtigter / Родитель или опекун | Взрослый пользователь, связанный с семейным аккаунтом. |
| **Trainer Access** / Trainerzugriff / Доступ тренера | Право тренера открывать страницы доступных ему учеников через отдельный тренерский вход (не через семейный аккаунт). |
| **Student Page** / Страница ученика | Страница данных конкретного ученика. Одна и та же страница используется и внутри семейного кабинета (после выбора ребёнка), и в тренерском доступе — с разными правами на отдельные блоки (например, финансовые данные). |

## Уточнения

- **Family Account** — единственная точка входа семьи; отдельных логинов
  «студент» и «родитель» на первом этапе не существует (см.
  `memory/BUSINESS_RULES.md`, правила 6–7).
- **Student Page** — не отдельный «Student Portal», а общий компонент,
  переиспользуемый и семьёй, и тренером (см.
  `docs/architecture/FAMILY_ACCOUNT_CONCEPT.md`).
- Проект по-прежнему называется `JKL_STUDENT_PARENT_PORTAL` — это название
  описывает назначение портала (студенты и родители как конечные
  пользователи), а не архитектуру с двумя отдельными интерфейсами.

Список будет дополняться по мере согласования терминов с пользователем.
