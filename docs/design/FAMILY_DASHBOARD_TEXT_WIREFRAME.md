# Текстовый wireframe — Family Dashboard

Это текстовые макеты для **desktop landscape**, только структура блоков и
их расположение. Финальный дизайн (цвета, шрифты, точные размеры в
пикселях) не определяется в этом документе — см. `docs/design/DESIGN_SYSTEM_PLAN.md`
для плана дизайн-системы.

Соответствует ТЗ `prompts/family/dashboard.md` (FAMILY-001) и
`prompts/family/my_family.md` (FAMILY-002).

**Подтверждённая модель, отражённая во всех сценариях ниже:**
- переключатель ребёнка — отдельная строка **под** верхней панелью, не
  часть самой панели (компактная при одном ребёнке, полноценная
  горизонтальная панель при нескольких);
- по умолчанию после входа открыт раздел «Мои тренировки» — активна именно
  эта кнопка; отдельного неименованного «обзора» не существует.

```
│ [ЛОГО JKL]   Семья: "Ивановы"        Привет, семья Ивановых!             │
│                                        [ 🔔 Уведомления ] [⚙ Настройки] [Выход] │
├──────────────────────────────────────────────────────────────────────────┤
│  Выбранный ребёнок: Мария Иванова                                        │
│                                                                            │
│   ┌───────┐   Мария Иванова                                              │
│   │ фото  │   Возраст: 9 лет (12.03.2017)                                │
│   │       │   Группа: Junior A   Спорт: Дзюдо                            │
│   └───────┘   Текущий пояс: жёлтый   →   Следующий пояс: жёлто-оранжевый │
│                                                                            │
│      ( o )  Возраст допуска к экзамену        ( o )  Рейтинговые баллы   │
│      осталось 6 мес.                          120 / 150 баллов          │
│                                                                            │
├──────────────────────────────────────────────────────────────────────────┤
│ [Моя семья] [Мои тренировки]* [Мои достижения] [Мои сертификаты]         │
│ [Мои мероприятия] [Необходимые техники] [Договор и оплата]               │
│  * — активна по умолчанию                                                │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                            │
│   МОИ ТРЕНИРОВКИ (открыто по умолчанию)                                 │
│                                                                            │
│   ─ Пн 18:00 Junior A — зал 1                                            │

│   ─ Сб 10:00 Открытая тренировка                                         │
│                                                                            │
└──────────────────────────────────────────────────────────────────────────┘
```

Так как привязан один ребёнок — он выбран автоматически, переключатель
детей отображается компактно отдельной строкой под верхней панелью (просто
имя, без карточек выбора).

## B. Family Dashboard — два ребёнка (переключатель)

```
┌──────────────────────────────────────────────────────────────────────────┐
│ [ЛОГО JKL]   Семья: "Ивановы"        Привет, семья Ивановых!             │
│                                        [ 🔔 ] [⚙ Настройки] [Выход]        │
├──────────────────────────────────────────────────────────────────────────┤
│  Выберите ребёнка:                                                       │
│  ┌─────────────────────────┐   ┌─────────────────────────┐              │
│  │ [фото] Мария Иванова     │   │ [фото] Пётр Иванов        │              │
│  │ Пояс: жёлтый             │   │ Пояс: белый               │              │
│  │ ▓▓▓▓▓ ВЫБРАНО ▓▓▓▓▓      │   │                           │              │
│  └─────────────────────────┘   └─────────────────────────┘              │
│                                                                            │
│   ┌───────┐   Мария Иванова                                              │
│   │ фото  │   Возраст: 9 лет   Группа: Junior A   Спорт: Дзюдо           │
│   └───────┘   Текущий пояс: жёлтый  →  Следующий: жёлто-оранжевый        │
│                                                                            │
│      ( o )  Возраст допуска к экзамену        ( o )  Рейтинговые баллы   │
│      осталось 6 мес.                          120 / 150 баллов          │
│                                                                            │
├──────────────────────────────────────────────────────────────────────────┤
│ [Моя семья] [Мои тренировки]* [Мои достижения] [Мои сертификаты]         │
│ [Мои мероприятия] [Необходимые техники] [Договор и оплата]               │
│  * — активна по умолчанию                                                │
├──────────────────────────────────────────────────────────────────────────┤
│   МОИ ТРЕНИРОВКИ — данные для Марии                                      │
└──────────────────────────────────────────────────────────────────────────┘
```

При выборе «Пётр Иванов» весь блок профиля, оба круглых индикатора и нижняя
динамическая область обновляются на данные Петра — без повторного входа.
Открытый раздел (в этом случае «Мои тренировки») при переключении ребёнка
не меняется, меняется только его содержимое.

## Примечание

Все размеры, отступы, шрифты и точные пропорции — не финальные и не
задаются в пикселях. Это структурная раскладка блоков для визуального
согласования подхода, а не итоговый дизайн.
