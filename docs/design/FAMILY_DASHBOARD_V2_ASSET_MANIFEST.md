# Family Dashboard Concept v2 — Asset Manifest

## 1. Официальное имя файла

`docs/screenshots/Family_Dashboard_Concept_v2.png`

## 2. Статус

Ожидается создание изображения. На момент создания этого манифеста файл
`docs/screenshots/Family_Dashboard_Concept_v2.png` **отсутствует** — только
`Family_Dashboard_Concept_v1.png` существует в `docs/screenshots/`.

## 3. Исходные документы

- `docs/design/FAMILY_DASHBOARD_V2_VISUAL_BRIEF.md`
- `docs/design/FAMILY_DASHBOARD_V2_ACCEPTANCE_CHECKLIST.md`
- `docs/design/FAMILY_DASHBOARD_CONCEPT_V2_REQUIREMENTS.md`
- `docs/design/FAMILY_DASHBOARD_TEXT_WIREFRAME.md`
- `docs/screenshots/Family_Dashboard_Concept_v1.png`

## 4. Обязательные состояния внутри изображения

A. Семья с одним ребёнком.
B. Семья с двумя детьми.
C. Открытый раздел «Моя семья».
D. Открытый раздел «Договор и оплата».

## 5. Обязательные элементы

- приветствие;
- верхняя панель;
- отдельный переключатель детей под верхней панелью;
- профиль выбранного ребёнка;
- два круглых индикатора;
- 7 dashboard-кнопок;
- одна активная кнопка;
- нижняя динамическая область;
- оба состояния допуска по возрасту;
- отсутствие бокового меню;
- отсутствие «Мои курсы»;
- отсутствие банковских реквизитов.

## 6. Технические требования к изображению

- PNG;
- альбомный формат;
- широкий desktop dashboard;
- рекомендуемое разрешение не ниже 1536×1024;
- читаемый текст;
- без обрезанных блоков;
- единый стиль всех четырёх состояний.

## 7. Версия

- v1 — первый концептуальный макет;
- v2 — исправленная версия после UX review;
- v2 не заменяет v1, оба файла сохраняются для истории.

## 8. Порядок приёмки

1. Поместить изображение в `docs/screenshots/`.
2. Проверить валидность PNG и разрешение.
3. Проверить по acceptance checklist.
4. Записать замечания пользователя.
5. После утверждения присвоить статус Design Approved.
6. Только после этого переходить к выбору технического стека.
