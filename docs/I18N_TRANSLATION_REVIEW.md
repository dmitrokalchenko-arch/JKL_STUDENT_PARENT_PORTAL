## Спорные/неоднозначные термины, требующие решения перед продакшном

1. **Турецкий `rating.title` = "Puan durumu"** ("состояние баллов") — выбрано
   как наиболее нейтральный вариант перевода «Рейтинговые баллы»; в
   контексте боевых искусств может быть принят другой устоявшийся термин.
2. **Румынская форма плюрализации с предлогом «de»** (`years_other: "{{count}}
   de ani"`) — грамматически стандартна, но это самое сложное из всех
   реализованных правил, специально просим отдельно перепроверить.
3. **Упрощение статуса тренировки** (`statuses.enrolled` /
   `statuses.register`) — в оригинальном русском варианте
   («Записан/Записана/Записаться») было родовое согласование по полу
   студента; при переводе на 12 языков от родового согласования сознательно
   отказались в пользу двух универсальных состояний. Если родовое
   согласование критично для русского/украинского/польского (все три —
   языки с грамматическим родом), потребуется отдельная ревизия схемы
   ключей.
4. **Арабские формы плюрализации `_two` (двойственное число)** — например,
   «سنتان» (2 года) — реализованы по правилам CLDR, но это наименее
   стандартная для остальных 11 языков грамматическая категория и наиболее
   вероятное место ошибки при отсутствии носителя для проверки.
5. **`header.greeting` во всех языках** содержит слово «семья» вживую в
   шаблоне (не в передаваемых данных) — при добавлении новой семьи с иным
   грамматическим родом фамилии (актуально для русского/украинского/
   польского, где обращение может зависеть от рода фамилии) текущий
   единый шаблон не учитывает это различие.

## Что не проверялось

- Ни один перевод не показывался живому носителю языка.
- Не проводилась проверка юридической/финансовой терминологии раздела
  «Договор и оплата» на соответствие возможным требованиям локального
  законодательства (не входило в задачу — мок-данные, не боевой текст
  договора).
- Не проверялось поведение экранных дикторов (screen readers) на арабском
  RTL-контенте.
